# TrustAgriLLM
TrustAgriLLM: A blockchain-trusted federated multimodal intelligence framework for privacy-preserving agricultural disease assessment and AI-powered decision support.

Overview:
--------
TrustAgriLLM is a blockchain-trusted federated multimodal intelligence framework designed for privacy-preserving agricultural disease assessment and intelligent decision support. The framework combines Federated Learning (FL), Blockchain-based Provenance Management, Trust-Aware Aggregation, and Multimodal Large Language Models (MLLMs) to enable secure, transparent, and context-aware agricultural intelligence.

Unlike conventional plant disease detection systems that stop at classification, TrustAgriLLM transforms disease predictions into actionable agricultural insights by integrating plant images, environmental observations, weather conditions, crop metadata, and farmer observations.

Key Features:
------------ 
Privacy-preserving plant disease assessment using Federated Learning
Blockchain-based provenance and trust management
Trust-aware model aggregation and malicious update filtering
Multimodal context construction from heterogeneous agricultural data
MLLM-based reasoning and explainable agricultural intelligence
Context-aware environmental risk assessment
Agricultural decision-support guidance generation
